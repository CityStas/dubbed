# DUBBED

<img src="assets/main.jpg" alt="Лендинг DUBBED: смотри любое видео на русском" width="720">

Бесплатное расширение для Chrome/Firefox: Быстрая AI-озвучка фильмов, сериалов и видео прямо в браузере. Работает на доменах HDrezka; работает в VK, Telegram, YouTube и плеерах многих других сайтов.

Web: https://dvodev.space/apps/dubbed/

## Установка расширения

**Chrome**
1. Скачать `downloads/dubbed-chrome.zip` и распаковать.
2. Открыть `chrome://extensions`, включить «Режим разработчика».
3. «Загрузить распакованное расширение» → выбрать папку.

**Firefox**
1. Скачать `downloads/dubbed-firefox.xpi`.
2. `about:addons` → шестерёнка → «Установить из файла».
